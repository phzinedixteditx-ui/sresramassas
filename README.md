# Massa Master

Quero que você desenvolva um site profissional, moderno e totalmente funcional para um restaurante chamado:

SR E SRA MASSAS

Estou anexando neste projeto:

1. A LOGO oficial do restaurante.

2. Uma imagem do cardápio atual do restaurante.

IMPORTANTE:

- Use a LOGO ANEXADA no site.

- Não recrie, redesenhe ou altere a logo.

- A logo anexada é a identidade visual oficial da marca.

- Use a imagem do cardápio apenas como REFERÊNCIA para extrair as opções, ingredientes e identidade visual.

- NÃO quero que o site pareça uma cópia da imagem do cardápio.

- Quero transformar essa identidade em um site profissional de restaurante, com aparência de sistema de pedidos moderno.

- O site precisa parecer um produto profissional que poderia ser usado comercialmente por um restaurante real.

==================================================

==================================================

A identidade do Sr e Sra Massas utiliza principalmente:

- Preto

- Amarelo/dourado

- Branco para textos

Criar um visual sofisticado, elegante e moderno.

O amarelo/dourado deve ser utilizado para:

- Botões

- Destaques

- Preços

- Seleções

- Ícones

- Bordas importantes

- Chamadas para ação

Evitar excesso de amarelo.

Quero uma estética premium, parecida com um aplicativo moderno de restaurante.

Usar:

- Cards elegantes

- Bordas arredondadas

- Sombras sutis

- Gradientes muito discretos quando fizer sentido

- Tipografia moderna

- Ícones profissionais

- Espaçamento consistente

- Excelente hierarquia visual

NÃO criar um site genérico de IA.

NÃO usar aparência de template.

NÃO exagerar nas animações.
